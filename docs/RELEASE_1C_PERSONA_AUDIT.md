# Release 1C persona audit

Date: 2026-08-30

The repository's 18 audited persona lenses support the same narrow release:
explicit learner consent, current evidence, one useful clue, and a safe return
to coding. They do not support proactive background AI, automatic quota use,
generic encouragement, or outcome claims without learners.

| Lens | Required product behavior | Release response |
| --- | --- | --- |
| Maya, Fresh Eyes, Staff UX | Clear language, no surprise charge, visible target, usable phone layout | The offer appears beside the current error, states the data/call consequence accessibly, and keeps cue plus target visible at 390×500. |
| Pedagogy, Product Owner | Preserve productive struggle and give every paid turn value | One authored question plus one bounded diagnosis/hint; no full solution or empty meta-question. |
| Security, AI Quality | Browser/source text cannot author policy; hostile context cannot escape | Server reconstruction, canonical evidence, injection cases, evaluated-model eligibility, and output enforcement. |
| QA, SRE | Repeats, races, stale work, and degraded dependencies fail safely | Double-click idempotency, stale-generation discard, deterministic unavailable states, independent kill switch, and zero-retry browser coverage. |
| Finance | Cost is opt-in, bounded, measured, and reversible | Zero calls before click, one call per evidence episode, measured per-call cost, and operator kill switch. |
| PM, Business, Growth, Competitive, Contrarian | Ship the smallest coherent learning improvement; avoid synthetic market claims | One lesson-authored error class proves the vertical slice. Learner recovery, retention, and differentiation remain non-claims. |
| Staff SWE | Close a problem class at trusted boundaries | Shared canonical context, versioned request type, centralized output policy, and no UI-only authority workaround. |

## Verdict

Proceed with engineering validation under the dated founder exception. Do not
merge until the final complete model gate, deterministic suites, actual-browser
phase replay, CI, and review threads pass. Keep two-human judge calibration and
real-learner outcomes visibly unclaimed.
